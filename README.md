# gitcommands
Treinamento de comandos do GIT

# Primeiro passo

 - Estando na branch main, deve ser criado uma branch com seu nome usando o comando : git checkout -b seuNome

  - Apos criado a sua branch , certifiqui-se que nela está com o comando : git status 

   - Criar uma folder com o seuNome
   - Criar uma sb Folder com o nome variaveis_js
   - Dentro da folder variaveis_js, você irá criar um arquivo chamado variaveis.js

   Estrutura esperada: 
   gitcommands
     |-douglas
          |variaveis_js
                |variaveis.js
     |seuNome
            |variaveis_js
                |variaveis.js

feito isso , realizar : 
 - git status
 - git add . 
 - git commit -m "meu primeiro commit"
 - git push origin -u seuNome
